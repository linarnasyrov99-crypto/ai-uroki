Настраиваем ИИ-агента под себя

За этот урок агент узнает тебя и получит правила, научится защищать твои файлы, понимать голос и наведёт порядок в компьютере.

Как проходить урок

  1. Создай папку для работы с ИИ, например «ИИ» в Документах. Это твоё рабочее окружение: все проекты будут жить внутри.
  2. Открой в этой папке своего агента — Claude Code или Codex.
  3. Иди по шагам сверху вниз: копируй промт, вставляй агенту, отвечай на его вопросы.
  4. Когда шаг получился, отметь галочки внизу шага. Отметки сохраняются в этом браузере.

ЧАСТЬ 2. Сторожа — защита от опасных действий
Сторож — это маленькая программа, которую Claude Code сам запускает перед каждым действием агента. Если действие опасное, сторож его останавливает.

3. Правила сторожа:

   - нельзя агенту самому менять сторожей и settings.json — ни правкой файла, ни командой в терминале (запись, копирование поверх, перенос, удаление). Читать их можно.
4. Сторож проверяет не только команды в терминале, но и то, какие файлы агент читает и правит.
5. Когда сторож срабатывает, он пишет по-русски: «СТОРОЖ ОСТАНОВИЛ: <причина>. Не ищи обход: покажи, что хотел сделать, и жди моего слова».

Даём агенту инструменты и доступы

Сначала разберёмся, как устроен агент. Потом поставим ему рабочие режимы, научим глубоко искать в интернете и подключим Google и Telegram.

Как проходить урок

  1. Открой агента в своей рабочей папке, как в уроке 1.
  2. Сначала прочитай теорию ниже или пролистай презентацию — 5 минут.
  3. Практику проходи по шагам сверху вниз. После установки плагинов и инструментов агент попросит перезапустить Claude — это нормально.
  4. Ключи, пароли и коды вводишь только ты. Если агент просит прислать ключ в чат — не присылай.

6. После перезапуска (я напишу «перезапустил») перечисли простыми словами 5 главных режимов Superpowers и когда каждый срабатывает. Мне не нужно помнить их названия — ты включаешь их сам.
7. Допиши в мой AGENTS.md строку: «Если для задачи подходит режим Superpowers — используй его сам, не проси меня вызывать команды».

Собираем агенту набор поисковиков и учим его не верить первой ссылке. Три шага: инструменты, свой скилл с правилами, первое исследование по твоей теме.

2.1 Инструменты

🆕 Куда: Новая сессия🧠 Модель: Claude Opus 5.5📁 Папка: твоё рабочее окружение
Поставь мне инструменты для глубоких исследований в интернете (MCP-серверы). Я не программист: объясняй по-русски, без лишних терминов, и показывай прогресс: «готово 4 из 11».

Правила:
- Ключи я ввожу сам. Ты даёшь ссылку, где его взять, и готовую команду с меткой КЛЮЧ — я сам вставлю ключ и запущу команду в терминале. Ключ мне в чат не присылай и сам не записывай.
- Ключи проси строго по одному. Перед каждым одной фразой скажи, что даёт сервис и сколько бесплатно.
- Если я пишу «пропусти» — пропускай, набор работает и частично.
- Если сервер с таким именем уже есть — не ломай его, сначала спроси меня.

Шаг 0. Проверь claude --version и node --version. Если Node нет — отправь меня на nodejs.org и жди.

Шаг 1. Шесть инструментов без регистрации, ставь сразу:
claude mcp add --scope user --transport http parallel-search https://search.parallel.ai/mcp
claude mcp add --scope user --transport http you-search-free "https://api.you.com/mcp?profile=free"
claude mcp add --scope user --transport http anysearch https://api.anysearch.com/mcp
claude mcp add --scope user --transport http rivalsearch https://RivalSearchMCP.fastmcp.app/mcp
claude mcp add --scope user -e MODE=stdio -e DEFAULT_SEARCH_ENGINE=duckduckgo open-websearch -- npx -y open-websearch@latest
claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest

Шаг 2. Пять инструментов с бесплатным ключом, по одному, в этом порядке:
1) Tavily — поиск сразу со ссылками на источники. Ключ: https://app.tavily.com
   claude mcp add --scope user -e TAVILY_API_KEY=КЛЮЧ tavily -- npx -y tavily-mcp
2) Firecrawl — превращает любой сайт в чистый текст. Ключ: https://www.firecrawl.dev/app/api-keys
   claude mcp add --scope user -e FIRECRAWL_API_KEY=КЛЮЧ firecrawl -- npx -y firecrawl-mcp
3) Exa — поиск по смыслу, а не по словам. Ключ: https://dashboard.exa.ai/api-keys
   claude mcp add --scope user -e EXA_API_KEY=КЛЮЧ exa -- npx -y exa-mcp-server
4) Apify — соцсети, карты, маркетплейсы, отзывы. Ключ: https://console.apify.com/settings/integrations
   claude mcp add --scope user -e APIFY_TOKEN=КЛЮЧ apify -- npx -y @apify/actors-mcp-server --tools docs,actors,apify/rag-web-browser --ui false
5) Jina — читает PDF и научные статьи. Ключ: https://jina.ai/api-dashboard
   claude mcp add --scope user jina -- npx -y mcp-remote https://mcp.jina.ai/v1 --header "Authorization: Bearer КЛЮЧ"

Шаг 3. Проверь claude mcp list и покажи итог живыми словами: что подключено, что пропущено и чего я из-за этого пока не смогу.
Скажи мне полностью закрыть и заново открыть Claude — инструменты поднимаются при старте.
Если сервер не отвечает и я в России — почти всегда нужен VPN, скажи это прямо.

2.2 Свой скилл

🆕 Куда: Новая сессия, после перезапуска Claude🧠 Модель: Claude Opus 5.5📁 Папка: твоё рабочее окружение
Создай мне скилл deep-research — правила, как ты проводишь глубокие исследования с инструментами, которые мы поставили. Положи его в ~/.claude/skills/deep-research/SKILL.md.

Что должно быть в скилле:

1. Описание (description) — когда его включать: когда я пишу «дипресёрч», «исследуй», «найди всё про», «разбери рынок», «изучи конкурентов», «проверь факты», «собери отзывы», «найди контакты».

2. Таблица «задача → чем брать» по моим инструментам:
   быстрый ответ со ссылками — Tavily; «не знаю, как это называется» — Exa; прочитать страницу целиком — Firecrawl; соцсети, Google Maps, отзывы, маркетплейсы — Apify; PDF и статьи — Jina; зайти на сайт и покликать — Playwright; перепроверить результат — parallel-search, you-search-free, anysearch, open-websearch; форумы и соцсети широким неводом — rivalsearch.

3. Протокол глубины:
   - пойми задачу: зачем, какая глубина, география, язык; если всё ясно — не переспрашивай;
   - собери карту запросов: русские и английские варианты, синонимы, названия, отраслевой сленг;
   - иди минимум тремя независимыми путями — один поисковик не исследование;
   - нужную страницу читай целиком, а не по куску из выдачи;
   - иди туда, где живут люди: отзывы, форумы, комментарии, YouTube, Telegram-каналы;
   - цифры, цены и даты проверяй по двум независимым источникам;
   - разделяй: факт, обещание продавца, чей-то отзыв, твоя догадка;
   - назови слепые зоны: куда не смог зайти и где данные старые.

4. Как отвечать: сначала вывод в 2–3 предложениях, потом разбор по пунктам со ссылками, потом что не проверено и почему, насколько ты уверен, и один конкретный следующий шаг. По-русски, плотно, без воды.

5. Границы: не заходи туда, где нужен логин, если мне не дали доступ; не выдумывай данные вместо «не смог найти»; не обходи защиту сайтов; мои личные и рабочие данные не отправляй в бесплатные анонимные поисковики (anysearch, open-websearch, rivalsearch) — для чувствительного бери Tavily, Firecrawl, Exa.

Покажи мне текст скилла до сохранения. После моего «да» сохрани и скажи, как его проверить.

Коннектор к твоим чатам

Telegram

Агент читает твои чаты: находит, пересказывает, напоминает. Отправляет только после твоего «отправляй». Самый ответственный шаг: это доступ к твоему аккаунту.

🆕 Куда: Новая сессия; после перезапуска Claude вернись в неё🧠 Модель: Claude Opus 5.5📁 Папка: твоё рабочее окружение
Подключи мне Telegram через открытый сервер telegram-mcp (github.com/chigwell/telegram-mcp), как у моего наставника. Я не программист: перед каждой командой объясняй по-русски, что она делает. Это доступ к моему аккаунту, поэтому сначала покажи мне план и жди моего «да».

Правила безопасности (главное):
- Ключи, номер телефона, код из Telegram и пароль я ввожу сам. Ты их не видишь, не просишь прислать в чат и не записываешь. Файл с ключами (.env) заполняю я сам по твоей инструкции — сторож не даст тебе его читать, и это правильно.
- Режим только чтение плюс три инструмента отправки: send_message, reply_to_message, send_file. Удаление сообщений, выход из чатов, изменение профиля и контактов — выключить.
- Отправлять можно только файлы .pdf, .png, .jpg, .jpeg, .docx, .xlsx, .mp4.
- Расшифровку голосовых через внешние сервисы выключить.
- На три инструмента отправки поставь подтверждение: перед каждой отправкой Claude спрашивает меня. И допиши в AGENTS.md: «Перед любой отправкой в Telegram покажи получателя и текст целиком и жди моего “отправляй”».

Шаги:
1. Перед установкой посмотри, что внутри репозитория и какая лицензия. Если что-то подозрительно — не ставь и скажи почему.
2. Поставь сервер в папку ~/tools/telegram-mcp. Добавь в него библиотеку hachoir — без неё видео в Telegram уходят растянутыми.
3. Объясни, как мне получить api_id и api_hash на my.telegram.org (по шагам, с переводом кнопок), и как мне самому в терминале создать строку сессии — я введу номер и код сам.
4. Дай мне шаблон файла .env с метками вместо ключей, без самих ключей. Я впишу их сам и сохраню.
5. Подключи сервер к Claude (claude mcp add ... --scope user) и скажи мне перезапустить Claude.
6. Проверка после перезапуска: покажи список моих 5 последних чатов; потом предложи отправить в «Избранное» сообщение «Проверка связи» — отправь только после моего «отправляй».
7. В конце: что поставлено, где лежит, как отключить доступ (удалить сервер из Claude и завершить сессию в Telegram: Настройки → Устройства).

Красные линии — всегда только ты

  • Пароли, ключи и коды вводишь сам. Агенту их не пишешь.
  • Деньги, покупки и подписки — только твоим решением.
  • Отправка писем и сообщений от твоего имени — только после твоего «отправляй».
  • Удаление файлов — только после твоего «да».
Застрял или агент делает что-то странное — сделай скриншот и пришли в общий чат.

Бот, который ничего не забывает

Наговариваешь боту идею, задачу или «напомни завтра в 10» — агент по одной команде всё расшифрует и разложит, а напоминание придёт, даже если компьютер выключен.

Как проходить урок

  1. Открой агента в своей рабочей папке, как в прошлых уроках.
  2. Иди по шагам сверху вниз. Урок длинный — можно делить на два вечера: шаги 1–3 и 4–6.
  3. Понадобятся телефон с Telegram и аккаунт Google. Аккаунт на GitHub заведём по ходу.
  4. Токен бота, пароли и секреты GitHub вводишь только ты. Если агент просит прислать их в чат — не присылай.

Telegram-бот

Свой бот-входящие

Бот — это почтовый ящик для мыслей. Пишешь или наговариваешь ему что угодно, он молча копит. Ключ от бота хранится отдельно от рабочей папки.

🆕 Куда: Новая сессия🧠 Модель: Claude Opus 5.5📁 Папка: твоё рабочее окружение
Хочу личного Telegram-бота «входящие»: я пишу ему голосом и текстом идеи, задачи и напоминания, а ты потом по моей команде всё разбираешь. Отвечать бот не должен. Я не программист: веди по шагам, кнопки переводи на русский.

Правила безопасности:
- Токен бота — это ключ. Я ввожу его сам, ты его не видишь, не просишь прислать в чат и не записываешь в рабочее окружение.
- Ключи храним вне рабочего окружения: в папке .inbox-bot в моей домашней папке (на Windows — C:\Users\<я>\.inbox-bot).

Шаги:
1. Объясни, как создать бота в @BotFather: команда /newbot, имя, ник на _bot. Скажи, что BotFather пришлёт токен и что его никому нельзя показывать.
2. Создай папку .inbox-bot и в ней файл keys.txt с шаблоном:
   BOT_TOKEN=вставь_сюда_токен
   CHAT_ID=
   Открой мне этот файл в обычном редакторе. Я вставлю токен сам и сохраню. Сам файл не читай.
3. Попроси меня написать боту /start и любое слово.
4. Напиши маленький скрипт, который сам берёт токен из keys.txt, узнаёт мой chat_id через getUpdates и дописывает его в keys.txt. Токен скрипт не печатает на экран. Покажи мне только chat_id.
5. Проверка: пусть скрипт отправит от бота мне сообщение «Бот-входящие подключён ✅».
6. Допиши в мой AGENTS.md: «Бот-входящие: ключи в ~/.inbox-bot, читать их может только скрипт. Принимать сообщения только с моего chat_id».

Сборщик + GigaAM v3

Голос в текст

Скрипт забирает сообщения из бота и расшифровывает голосовые русской моделью GigaAM прямо на компьютере. Запускается только по твоей команде.

↩️ Куда: Та же сессия, что шаг 1🧠 Модель: Claude Opus 5.5📁 Папка: твоё рабочее окружение
Теперь сделай сборщик входящих. Работает только когда я попрошу, никаких проверок по расписанию.

Что поставить:
1. Python 3.11 или новее, ffmpeg и библиотеку onnx-asr (github.com/istupakov/onnx-asr, лицензия MIT) с моделью GigaAM v3 — вариант с пунктуацией (e2e). Перед установкой проверь README и лицензию, точное имя модели возьми оттуда. Поставь всё в отдельное окружение Python, чтобы не мусорить в системе. Для голосовых длиннее 20 секунд подключи VAD — он режет запись на куски, иначе модель обрежет текст.
2. Проверь расшифровку на коротком тестовом аудио.

Скрипт сборщика (положи в папку «Входящие/скрипт» в рабочем окружении):
- токен и chat_id берёт из ~/.inbox-bot/keys.txt и нигде их не печатает;
- забирает новые сообщения через getUpdates и запоминает, на каком остановился, чтобы не брать одно и то же дважды;
- принимает сообщения только с моего chat_id, остальные пропускает;
- текст сохраняет как есть, голосовые и кружки скачивает, переводит в wav через ffmpeg и расшифровывает GigaAM;
- всё дописывает в «Входящие/Новые.md»: дата и время, тип (текст/голос), текст;
- аудиофайлы после расшифровки не удаляет, а кладёт в «Входящие/Архив аудио»;
- в конце пишет, сколько сообщений забрал.

Объясни мне простыми словами: Telegram хранит сообщения боту только 24 часа, поэтому разбирать входящие надо хотя бы раз в сутки.

Проверка: я отправлю боту одно текстовое сообщение и одно голосовое. Запусти сборщик и покажи, что попало в «Новые.md».

GitHub Actions

Напоминания без компьютера

Бесплатные серверы GitHub раз в 20 минут проверяют список напоминаний и шлют тебе сообщение от бота. Компьютер для этого не нужен.

🆕 Куда: Новая сессия🧠 Модель: Claude Opus 5.5📁 Папка: твоё рабочее окружение
Сделай так, чтобы мой бот-входящие присылал мне напоминания в Telegram, даже когда компьютер выключен. Делаем через GitHub Actions — это бесплатные серверы GitHub, которые запускают скрипт по расписанию. Я не программист: объясняй каждый шаг.

Правила:
- Репозиторий только приватный: в напоминаниях личное.
- Токен бота и chat_id я сам вписываю в GitHub: Settings → Secrets and variables → Actions (Настройки → Секреты и переменные → Действия), имена TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID. В файлы и в чат их не пиши.
- Ничего платного не включать.

Шаги:
1. Поставь GitHub CLI (gh). Вход в аккаунт делаю я сам через браузер (gh auth login).
2. Создай приватный репозиторий «napominaniya» и склонируй его в «Входящие/napominaniya» в моём рабочем окружении.
3. Внутри:
   - reminders.json — список напоминаний: id, текст, время с часовым поясом, отправлено да/нет;
   - send.py — берёт напоминания, у которых время пришло и которые ещё не отправлены, шлёт каждое через sendMessage бота с «⏰» в начале и отмечает «отправлено»;
   - .github/workflows/remind.yml — запуск раз в 20 минут с 7:00 до 23:00 по моему часовому поясу (переведи в UTC, GitHub считает по UTC) и кнопка ручного запуска; после отправки сохраняет reminders.json обратно с пометкой [skip ci].
4. Объясни, почему раз в 20 минут: на приватном репозитории бесплатно 2000 минут в месяц, каждый запуск считается минимум за минуту. Посчитай, сколько выйдет в месяц.
5. Дай мне прямую ссылку на страницу секретов репозитория и жди, пока я впишу оба секрета.
6. Проверка: добавь тестовое напоминание «Проверка напоминаний» на время «сейчас», отправь в GitHub, запусти задание вручную и покажи, что оно прошло. Я подтвержу, что сообщение пришло.
7. Объясни честно: GitHub иногда опаздывает на 5–15 минут, поэтому точное время даёт Google Календарь, а бот — запасной канал прямо в Telegram.

Скилл «разбери входящие»

Одна команда на всё

Агент разбирает входящие: идеи — в файл идей, задачи — в список, напоминания — в календарь и бот.

🆕 Куда: Новая сессия🧠 Модель: Claude Opus 5.5📁 Папка: твоё рабочее окружение
Собери мне скилл «razbor-vhodyashchih». Он запускается, когда я пишу «разбери входящие», «что во входящих», «разбери бота». Сначала покажи мне текст скилла, создай только после моего «да».

Что делает скилл:
1. Запускает сборщик из «Входящие/скрипт» — забирает новые сообщения из бота и расшифровывает голосовые.
2. Читает «Входящие/Новые.md» и делит каждую запись на:
   - идея → дописать в «Входящие/Идеи.md» с датой и коротким заголовком;
   - задача без срока → в «Входящие/Задачи.md» как пункт «- [ ]»;
   - напоминание или дело со временем («напомни завтра в 10», «в пятницу позвонить маме») →
     а) событие в Google Календаре с уведомлением за 10 минут,
     б) запись в reminders.json в «Входящие/napominaniya», затем отправить изменения в GitHub, чтобы бот напомнил в Telegram.
   Если в одном голосовом несколько мыслей — разбить на отдельные пункты.
3. Время считать по моему часовому поясу из AGENTS.md. Если время непонятное («как-нибудь вечером») — не угадывать, а спросить меня.
4. Разобранные записи перенести из «Новые.md» в «Входящие/Архив/ГГГГ-ММ.md», чтобы «Новые.md» оставался пустым.
5. В конце короткий отчёт: сколько идей, задач и напоминаний, список напоминаний с датой и временем, что непонятно.

Правила скилла:
- Ничего не удалять, только переносить.
- Людям ничего не отправлять и в календарь никого не приглашать.
- Напоминать мне: Telegram хранит сообщения боту 24 часа, разбирать входящие надо раз в день.

После создания проверь скилл на том, что уже лежит во «Входящих».
